### 📖 About the Repository

This repository documents the laboratory exercises and algorithmic implementations for the **Design and Analysis of Algorithms (DAA)** curriculum. Each module demonstrates practical implementations of core algorithmic paradigms, complete with time/space complexity evaluations.

---

### 🧪 Experiments & Algorithmic Modules

<details open>
<summary><b>📂 EXER 1–3: Sorting, Brute Force & Divide-and-Conquer</b></summary>
<br>

| Module | Algorithms Covered | Paradigm | Time Complexity |
| :--- | :--- | :--- | :--- |
| **EXER 1** | Selection Sort, Bubble Sort | Basic Sorting | $\mathcal{O}(n^2)$ |
| **EXER 2** | String Matching, Closest Pair of Points | Brute Force | $\mathcal{O}(n \cdot m)$ / $\mathcal{O}(n^2)$ |
| **EXER 3** | Merge Sort, Quick Sort | Divide & Conquer | $\mathcal{O}(n \log n)$ |

</details>

<details>
<summary><b>📂 EXER 4–6: Trees, Advanced String Matching & Dynamic Programming</b></summary>
<br>

| Module | Algorithms Covered | Paradigm | Time Complexity |
| :--- | :--- | :--- | :--- |
| **EXER 4** | Heap Sort (Max/Min Heap) | Tree-based Sorting | $\mathcal{O}(n \log n)$ |
| **EXER 5** | Counting Sort, Horspool's Algorithm | Space-Time Tradeoff | $\mathcal{O}(n + k)$ / $\mathcal{O}(m \cdot n)$ |
| **EXER 6** | Floyd-Warshall All-Pairs Shortest Path | Dynamic Programming | $\mathcal{O}(V^3)$ |

</details>

<details>
<summary><b>📂 EXER 7–10: Greedy, Backtracking & Branch-and-Bound</b></summary>
<br>

| Module | Algorithms Covered | Paradigm | Time Complexity |
| :--- | :--- | :--- | :--- |
| **EXER 7** | Huffman Coding (Lossless Compression) | Greedy Strategy | $\mathcal{O}(n \log n)$ |
| **EXER 8** | Dijkstra's / Prim's / Kruskal's | Greedy Graph Algorithms | $\mathcal{O}(E \log V)$ |
| **EXER 9** | $N$-Queens Problem | Backtracking | $\mathcal{O}(N!)$ |
| **EXER 10** | 0/1 Knapsack Problem | Branch & Bound / DP | $\mathcal{O}(2^n)$ / $\mathcal{O}(n \cdot W)$ |

</details>
